# Day 2 – SQL Employee Database Practice

## Overview
Day 2 focuses on practicing SQL using an `Employees` table with 55 queries covering filtering, aggregation, grouping, sorting, and pattern matching.

## Topics Covered
- Basic `SELECT` queries
- `WHERE` clause filtering
- Aggregate functions: `SUM()`, `AVG()`, `COUNT()`, `MAX()`, `MIN()`
- `GROUP BY` and `HAVING`
- `ORDER BY` and `LIMIT`
- `DISTINCT` usage
- Comparison, logical, `IN`, `BETWEEN`, and `LIKE` operators
